The method of use of this project is listed here. You may need to need to download and install BlueJ for a good user experience. 

Add a Debit card -
Enter the details for debit Card and credit card. Enter your own or use the sample below.

balanceAmount=50000 
cardId=17320943 
bankAccount="325013KTM907" 
issuerBank="Sky Banks" 
clientName="John Taylor" 
pinNumber=5340 
cvcNumber=890 
interestRate=16.0 

Click on "Add" to the right in the Debit card panel.
Click on "Add" to the right in the Credit card panel. 
Note that you cannot add the same card twice.

Feature 1:

  i. Enter a certain balanceAmount. You can click on "Display" button on the right of the debit card panel to display your
     entered balance amount. 
 ii. Enter a certain withdrawal amount and set the date before clicking on the "Withdraw" button.   
iii. Click on the "Display" button. 

Feature 2:

	 When valid values for card ID, withdrawal amount, withdrawal date and pin number is re-entered, a display box displays all the entered value.

  i. Erase all the entered values.
 ii. Re-enter the values for card ID, withdrawal amount, withdrawal date and pin number. 

Feature 3: 
  i. Enter a certain credit limit and the value for gracePeriod. Do not enter a value greater than 2.5 times the balanceAmount. 
 ii. Click on the "Display" button.

Feature 4:
     When a valid amount for card ID is re-entered, a display box display the credit limit amount and the value for grace period. 
	   Note that you must set credit limit beforehand for this to work. 
	 
  i. Set credit limit
 ii. Erase all fields. 
iii. Re-enter the card ID of the credit card.
  
Feature 5:
  i. Click on "Cancel" button to cancel the credit card. 

For form validation, the fields for which you entered wrong values or left it empty when adding a debit card or credit card, the error message will
inform you about those specific fields.
